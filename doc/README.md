# 米拉漫展 (Mira Comic-Con) 交接文档

> 一句话介绍：一个连接漫展 coser 与摄影师的约拍交易平台。C 端是 uniapp 小程序（当前主跑 H5，目标微信小程序），配一个独立的后台管理系统，后端是 Go + PostgreSQL + Redis，另有一个从喵特(nyato.com)抓取漫展数据的定时采集程序。

本目录是给接手这个项目的同事看的「人话版」文档，不是给 AI 代理读的规范文件。想了解每个模块的实现细节和开发历史，请直接看仓库根目录的 `AGENTS.md`（约 900 行，是整个项目的知识库，AI 协作时也在用）。

## 项目速览

### 它是什么

米拉漫展是一个漫展约拍平台，围绕「漫展」这个场景把 coser 和摄影师连接起来：

- **Coser 视角**：浏览漫展信息 → 关注感兴趣的漫展 → 找摄影师 → 看摄影师作品和报价 → 预约下单 → 和摄影师聊天 → 拍摄后评价。
- **摄影师视角**：注册后一键开通摄影师身份（闲鱼式双角色）→ 维护主页资料和作品集 → 接单管理 → 申请认证拿「黄V」。
- **管理员视角**：后台工作台看数据 → 审核摄影师认证 → 管理订单/漫展/用户 → 维护首页轮播图 → 发布通知公告 → 管理作品/评论/标签。

### 组成部件

| 部件 | 技术 | 位置 | 开发端口 |
|------|------|------|---------|
| C 端小程序 | uniapp (Vue3 + TS + Pinia + Vite)，暗色霓虹主题 | `src/` | `:5173` |
| 后台管理端 | soybean-admin 改造 (Vue3.5 + Vite8 + NaiveUI)，浅色专业风 | `admin/` | `:5174` |
| 后端 API | Go 1.22 + Gin + pgx + PostgreSQL + Redis | `server/` | `:8080` |
| 数据采集 | Go 定时任务，抓取 nyato.com 漫展数据 | `server/cmd/ingest` | cron 调度 |

### 基础设施

| 服务 | 容器名 | 端口 | 凭据 |
|------|--------|------|------|
| PostgreSQL | `comic-pg` | `5433`（映射容器内 5432） | comic / comic123，库名 comic |
| Redis | `comic-redis` | `6379` | 无密码 |

根目录的 `docker-compose.yml` 是参考用（注意里面的 API 服务容器名是 `comic-postgres`，而实际本机跑的是 `comic-pg`，由 `start.sh` 创建），日常开发一般不用 compose，直接跑本地进程即可。

## 推荐阅读顺序

刚接手建议按这个顺序来，大约半天能建立完整印象：

1. **本文档通读一遍**，知道有哪些东西。
2. **`01-quickstart.md`**：把环境搭起来，确认能看到 C 端首页、后台登录页、后端接口三个都正常。
3. **`02-architecture.md`**：理解三层结构和认证体系，这是后面改代码的地基。
4. **`AGENTS.md`**：不用从头逐行读，先看开头的 `OVERVIEW` / `STRUCTURE` / `WHERE TO LOOK` 三节，之后按需搜索。它按功能模块组织，改哪块查哪块。
5. **`docs/superpowers/specs/`**：挑你接下来要动的模块，读对应的设计文档，理解当初的取舍。
6. **按需查阅其余文档**：`03-modules.md`（功能清单）、`04-data-and-api.md`（表与接口）、`05-dev-guide.md`（规范）、`06-handover.md`（移交 checklist）、`07-history.md`（演进历程）。

## 交接时的几个提醒

- 后端**必须从 `server/` 目录启动**，否则读不到 `.env`，会连错数据库端口（`.env` 里 `DB_PORT=5433`，不是默认的 5432）。
- 全局代理（`100.64.0.11:7897`）会破坏 Gitee 推送，推送时用 `git -c http.proxy= -c https.proxy= push gitee master`，或直接跑 `./push-gitee.sh`。
- 后台的 admin token 每次登录都会轮换，所以浏览器里登录着的时候不要在终端再 curl 登录一次，会把浏览器会话顶掉。
- `AGENTS.md` 里提到「根目录缺 `.gitignore`」，这条已经过时，现在根目录有 `.gitignore`。
