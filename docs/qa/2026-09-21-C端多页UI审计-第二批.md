## 一、系统性问题（多页复现 → 应在共享层统一修，不是单页 bug）

### 🔴 S-1 「白字 + 青色/渐变底」对比度仅 ~2.4:1

| 位置 | 实测 | 要求 |
|------|------|------|
| 订单详情 状态横幅 `待确认`（42.7px） | **2.43:1** | 3:1（大字号） |
| 订单详情 状态横幅 `订单号：`（23.5px） | **~2.0:1** | 4.5:1 |
| 订单详情 状态横幅 `◆`（85.3px） | **2.21:1** | 3:1 |
| 首页「◆ 近期热门漫展」渐变条 白字 | 青端 **2.43:1** | 4.5:1 |

**根因**：`#06b6d4`（`$neon-cyan`）亮度较高，**白字压不住**。这与第一批在「我的套餐管理页」提交按钮上修的**是同一个病根**（当时改为深字 `$dark-bg-primary` → 4.95–8.07:1）。

**建议**：
- 青色实底上的文字改**深色** `$dark-bg-primary`（青底 8.07:1 ✅）
- 或把底色调深（如 `#0e7490`），但会削弱霓虹观感
- **渐变条**同理：白字 → 深字，或在渐变上叠深色蒙版

### 🔴 S-2 标签 pill「紫字 on 紫底」3.8:1

| 位置 | 实测 |
|------|------|
| 首页 热门标签 ×9（日系/古风/科幻/清新/少女/暗黑/哥特/朋克/汉服） | **3.8:1** |
| 漫展详情 标签区 | **3.8:1** |

**根因**：`color: #a855f7`（`$neon-purple`）+ `background: rgba(168,85,247,0.15)` —— 同色系叠加导致对比不足。
**建议**：文字改用已新增的 `$neon-purple-bright: #c084fc`（→ **6.09:1** ✅），与「面议」标签保持一致。

### 🟡 S-3 「▼」下拉箭头 3.92:1（摄影师列表）

小元素，跟随上级文字色；提到 `$dark-text-secondary` 即可达标。

### 🟡 S-4 `uni-switch` 触控高度 36px < 44px（设置页）

开关高 36px。**建议**：给开关容器补 `min-height: 44px`，或包一层 44px 点击区。

## 二、已排除的「误报」（方法学，避免误导）

审计脚本初版报了几类**假阳性**，均已逐一核实后排除：

| 报出项 | 真相 |
|--------|------|
| 「米拉漫展」标题 1.34:1 | **渐变文字**：该 span `-webkit-text-fill-color: rgba(0,0,0,0)`，实际颜色由父级渐变绘制。截图确认清晰可读 → 用 `color` 算对比度对该写法无效 |
| TabBar 的 `24x50 / 24x24 / 20x13` 小触控 | uni-app **内置 TabBar 的内部元素**，真实点击区是外层单元格 → 非问题 |
| `uni-swiper-dot` 8×8 | 轮播**装饰性圆点**（不承载操作） |
| `uni-page-head-btn` 26×26 | **uni-app 内置导航栏返回按钮**（`navigationStyle` 非 custom 的页面才有）→ 非我们代码，改动面在页面配置 |

**结论**：真实问题集中在 **S-1 ~ S-4**，其中 **S-1 / S-2 是跨页复现的系统性配色问题**。

## 四、建议的修复顺序

1. **S-2 标签 pill**（影响面最广、改法最明确）→ 全站 tag 样式统一用 `$neon-purple-bright`
2. **S-1 青色/渐变底白字**（对比度最差、含订单详情核心信息）→ 统一改深字
3. **S-3 ▼ 箭头**、**S-4 switch 高度**（局部小改）

> 说明：S-1 / S-2 若在**共享 SCSS / token** 层收敛，会同时修好所有页面；但会改变多页观感，**需你确认后再动**。
