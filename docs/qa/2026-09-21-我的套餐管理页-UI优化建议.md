- **视觉基线截图**：`/tmp/opencode/ui-list-390.png`（列表态）· `/tmp/opencode/ui-form-390.png`（表单态）
- **评估视口**：390 × 844（iPhone 14 逻辑分辨率，与 C 端移动优先一致）
- **评估依据**：`ui-ux-pro-max` skill 的优先级表（Accessibility=CRITICAL → Touch=CRITICAL → Layout/Typography=HIGH/MEDIUM）
- **重要声明**：**本文档只出建议，未改任何代码。** 你确认要改哪几条，我再动手。

## 二、建议清单（按优先级）

### 🔴 P0 — CRITICAL（无障碍/触控，建议必修）

**P0-1 触控目标全部提到 ≥44px**

| 元素 | 现状 | 建议 |
|------|------|------|
| 编辑 / 删除 | 高 **27px** | → 高 **44px**（`padding` 竖向加到 ~12rpx→ 实际 44px），或改为**图标按钮**并把热区撑到 44 |
| 一键预填 / 新增 | 高 31–32px | → 高 **44px** |
| 返回列表 | 高 41px | → 高 **44px** |

> 影响：移动端误触率高，尤其「删除」是破坏性操作却只有 27px 高。

**P0-2 三级文本对比度提亮到 ≥4.5:1**
- `.meta-item`（时长）与 `.field-hint`（表单提示）当前用 `$dark-text-tertiary`(#64748b, 3.75:1)
- **建议**：改用 `$dark-text-secondary`(#94a3b8, **6.97:1**)
- 若必须保留三级灰的视觉层次，则把它限定在**纯装饰**用途，不要承载「时长」这类必要信息

**P0-3 提交按钮对比度不足（3.96:1）**
- 现状：白字 + `$neon-gradient`(紫→青)
- **建议**（择一）：① 字形加粗到 600 并加大到 16px；② 用更深的紫 `#7c3aed` 作底（白字对比约 5.5:1）；③ 文字改深色 `#0a0a1a`（对青紫底约 8:1）

### 🟠 P1 — HIGH

**P1-4 弹窗按钮英文（真实缺陷，见测试报告 D-1）**
- `uni.showModal` 显示 `Cancel` / `OK`
- **建议**：设 `uni.setLocale('zh-Hans')`，或给每个 modal 显式传 `cancelText:'取消', confirmText:'确定'`
- 影响面是**全局**的（删除套餐、退出登录、拉黑…）

**P1-5 过小字号提到 ≥12px**
- 状态标签 10.4px、元信息 11.44px、hint 11.44px
- **建议**：统一到 **12px（`$font-size-xs`）** 起步；状态标签可 12px + 略加 padding

### 🟡 P2 — MEDIUM

**P2-6 价格与名称的层级**
- 实测 名称 15.6px > 价格 13.52px。但**价格是用户决策的第一信息**
- **建议**：价格提到 **≥15px**（或与名称同号并加粗），名称略降为 15px —— 让「¥399」成为视觉焦点

**P2-7 表单「时长」缺单位提示**
- 输入框 placeholder 只写「例如：60」，用户不知单位
- **建议**：placeholder 改「例如：60（分钟）」或在右侧加单位后缀

**P2-8 错误提示为 toast，无 inline error**
- skill：错误应**靠近字段**呈现（并有 `aria-live`），当前仅 `/价格需为不小于 0 的数字` toast
- **建议**：价格字段下方加 inline 红色提示（与 `.field-hint` 同位、换色）

### 🟢 P3 — LOW

**P3-9 工具栏在小屏偏挤**（右缘 373/390，仅 17px 余量）
- **建议**：小屏下把「一键预填平台模板」文案缩短为「预填模板」，或把两个按钮换行/收进「⋯」

**P3-10 空态视觉偏弱**（◇ 图标 + 两行灰字）
- **建议**：图标加大并加霓虹色，或补一个主 CTA 按钮（直接触发「新增套餐」）

## 三、已经很好、**不建议动**的部分

- **主文本/标签/价格标签对比度**：14.49 / 6.97 / 6.50 / 6.14 —— 全部达标，霓虹配色在深底上可读性良好
- **输入框与提交按钮高度**：46 / 48px，已达触控标准
- **编辑/删除按钮间距**：8px，刚好达标（但按钮本身高度不足，见 P0-1）
- **无横向滚动**：390 宽下 `scrollWidth == innerWidth`，布局不溢出
- **三态价格视觉编码**（面议/互勉/固定价 三种颜色 + 文案）—— 清晰且一致，是全页最好的设计决策之一
- **暗色霓虹主题一致性**：全部走 `$dark-*` / `$neon-*` token，无硬编码色
