# P2c 独立 Web 后台管理端 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭建米拉漫展独立 Web 后台管理端（soybean-admin 改造）：Dashboard 数据面板 + 摄影师认证审核 + 订单管理 + 漫展管理，并入现有 Go 后端 `/api/admin/v1/*`。

**Architecture:** 后端在现有 :8080 Gin 增加 `/api/admin/v1/*` 路由组（独立 `admins` 表 + bcrypt 密码 + DB token 认证 + AdminAuthRequired 中间件，与 C 端 user token 完全隔离）；前端拉取 soybeanjs/soybean-admin 置于 `admin/` 子目录改造（移除 i18n/演示页、浅色电商风、接管理 API）。

**Tech Stack:** Go 1.22 + Gin + pgx + golang.org/x/crypto/bcrypt（唯一新依赖）；Vue3.5 + Vite8 + TS6 + Pinia3 + NaiveUI + UnoCSS + ECharts（soybean 自带）。

## Global Constraints

- 现有 C 端认证是 **DB token**（`user_tokens` 表 + `GetUserByToken`），无 JWT 库。Admin token 采用同构模式（`admins.token` 列），**禁止引入 golang-jwt**。
- 唯一新 Go 依赖：`golang.org/x/crypto/bcrypt`。密码哈希用 bcrypt 默认 cost。
- 订单状态机：`pending→confirmed`、`confirmed→completed`、`pending/confirmed→cancelled`；`canTransition(b.Status, newStatus)` 为合法转移判据；其他 409。
- 管理 API 前缀 `/api/admin/v1/`；除 login 外全部 `AdminAuthRequired`。
- 管理员改订单：**跳过 actorTag 校验但保留 `canTransition`**（新增 `BookingService.AdminUpdateStatus`，不改 `UpdateStatus` 现有 default-deny 逻辑）。
- 数据库：`comic-pg` docker（:5433）；`comic_events` 表（非 events）；审核开关复用 `photographers.certified`（P2a 列）。
- 前端目录 `admin/`（git 并入主仓库，删除模板自身 `.git`）；Node ≥ 20（本机 v22.18.0 ✓）。
- 后台浅色电商风（soybean 默认），**不做** C 端暗色霓虹。
- 种子管理员：`admin` / `admin123`（bcrypt 哈希写入迁移；生产必须改密——AGENTS.md 注明）。
- 所有 `go build ./...`、`go test ./...`、`npx vue-tsc --noEmit` 必须过。
- 服务重启：从 `server/` 目录启动；`kill $(ss -tlnp | grep 8080 | grep -oP 'pid=\K[0-9]+')`；无 pkill。

```go
package service

import (
	"context"
	"crypto/rand"
	"encoding/hex"
	"errors"
	"time"

	"golang.org/x/crypto/bcrypt"
	"github.com/Maluslock/comic/server/internal/repository"
)

var ErrInvalidCredentials = errors.New("invalid credentials")

type AdminService struct{ repo *repository.AdminRepo }

func NewAdminService(repo *repository.AdminRepo) *AdminService { return &AdminService{repo: repo} }

func newAdminToken(id int64) string {
	b := make([]byte, 16)
	_, _ = rand.Read(b)
	return "adm_" + hex.EncodeToString(b)
}

func (s *AdminService) Login(ctx context.Context, username, password string) (string, *repository.AdminRow, error) {
	a, err := s.repo.GetAdminByUsername(ctx, username)
	if err != nil {
		return "", nil, ErrInvalidCredentials
	}
	if bcrypt.CompareHashAndPassword([]byte(a.PasswordHash), []byte(password)) != nil {
		return "", nil, ErrInvalidCredentials
	}
	token := newAdminToken(a.ID)
	if err := s.repo.SetToken(ctx, a.ID, token, time.Now().Add(24*time.Hour)); err != nil {
		return "", nil, err
	}
	return token, a, nil
}

func (s *AdminService) Authenticate(ctx context.Context, token string) (*repository.AdminRow, error) {
	return s.repo.GetAdminByToken(ctx, token)
}
```

package middleware

import (
	"net/http"

	"github.com/gin-gonic/gin"
	"github.com/Maluslock/comic/server/internal/repository"
)

func AdminAuthRequired(admins *repository.AdminRepo) gin.HandlerFunc {
	return func(c *gin.Context) {
		auth := c.GetHeader("Authorization")
		if len(auth) <= 7 || auth[:7] != "Bearer " {
			c.AbortWithStatusJSON(http.StatusUnauthorized, gin.H{"error": "missing admin token"})
			return
		}
		token := auth[7:]
		a, err := admins.GetAdminByToken(c.Request.Context(), token)
		if err != nil {
			c.AbortWithStatusJSON(http.StatusUnauthorized, gin.H{"error": "invalid admin token"})
			return
		}
		c.Set("admin_id", a.ID)
		c.Next()
	}
}

func AdminID(c *gin.Context) int64 {
	v, _ := c.Get("admin_id")
	id, _ := v.(int64)
	return id
}
```

package handler

import (
	"net/http"

	"github.com/gin-gonic/gin"
	"github.com/Maluslock/comic/server/internal/service"
)

type AdminHandler struct{ svc *service.AdminService }

func NewAdminHandler(svc *service.AdminService) *AdminHandler { return &AdminHandler{svc: svc} }

func (h *AdminHandler) Login(c *gin.Context) {
	var req struct {
		Username string `json:"username" binding:"required"`
		Password string `json:"password" binding:"required"`
	}
	if err := c.ShouldBindJSON(&req); err != nil {
		c.JSON(http.StatusBadRequest, gin.H{"error": "username and password required"})
		return
	}
	token, a, err := h.svc.Login(c.Request.Context(), req.Username, req.Password)
	if err != nil {
		c.JSON(http.StatusUnauthorized, gin.H{"error": "invalid credentials"})
		return
	}
	c.JSON(http.StatusOK, gin.H{"token": token, "admin": gin.H{"id": a.ID, "username": a.Username, "role": a.Role}})
}
```

```go
// AdminUpdateStatus bypasses actor ownership checks; the admin is neither coser nor photographer.
// State-machine transition validation (canTransition) is STILL enforced.
func (s *BookingService) AdminUpdateStatus(ctx context.Context, bookingID int64, newStatus string) (*BookingItem, error) {
	b, err := s.queries.GetBookingByID(ctx, bookingID)
	if err != nil {
		if errors.Is(err, pgx.ErrNoRows) {
			return nil, ErrBookingNotFound
		}
		return nil, err
	}
	if !canTransition(b.Status, newStatus) {
		return nil, ErrInvalidTransition
	}
	updated, err := s.queries.UpdateBookingStatus(ctx, bookingID, newStatus)
	if err != nil {
		return nil, err
	}
	switch newStatus {
	case "confirmed":
		s.notify(ctx, b.CoserID, "info", "预约已确认", "摄影师已确认接单，请按时赴约")
	case "cancelled":
		s.notify(ctx, b.CoserID, "warning", "预约已取消", "您的预约已被取消")
	case "completed":
		s.notify(ctx, b.CoserID, "success", "拍摄已完成", "记得去评价本次拍摄哦")
	}
	return bookingToItem(updated), nil
}
```

## 风险与决策记录

- **bcrypt 占位哈希**：Task 1 Step 2 用 `go run` 生成真实哈希替换占位——`$2a$10$7EqJtq98...` 仅为占位，**必须替换**，否则登录失败。
- **角色隔离**：admins.token 与 user_tokens 完全独立（不同表、不同 Bearer 中间件），C 端 token 无法访问 admin 路由，反之亦然。
- **管理员订单操作**：跳过身份校验但保留状态机——`completed→pending` 409 与 C 端一致。
- **soybean-admin 版本漂移**：模板目录结构以实际拉取为准；本计划 Step 5-8 页面文件名/路由以 soybean v4+ 实际结构适配，若差异大以模板实际 schema 为准写页面。
- **i18n 移除**：若模板依赖深（部分第三方组件引用），可降级为保留 i18n 但仅启用 zh-CN，页面不显示语言切换器；本计划按「移除」优先。
